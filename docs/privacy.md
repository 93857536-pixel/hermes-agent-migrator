# Privacy Policy / 隐私政策

Hermes Agent Migrator is a local-first configuration migration, backup,
restore, and cloud storage tool. This policy explains what information is
handled and why. Hermes Agent Migrator 是一款本地优先的配置迁移、备份、
恢复与云端存储工具。本政策说明所处理的信息及其用途。

## Information collected / processed / 收集 / 处理的信息

- **Account identifier** — used for cloud storage and configuration
  management. 账户标识 —— 用于云端存储与配置管理。
- **Device identifier** — a *random* UUID v4, generated on first cloud use
  and stored locally. It is **not** a hardware fingerprint and carries no
  user name, host name, serial, or MAC. 设备标识 —— 随机 UUIDv4，首次使用
  云功能时本地生成；**不是**硬件指纹，不含用户名/主机名/序列号/MAC。
- **Public IP** — processed by the cloud service for security, diagnostics,
  and abuse prevention. 公网 IP —— 由云服务处理，用于安全、诊断与滥用防护。
- **Configuration metadata** — size, SHA-256, and upload timestamp. 配置元
  数据 —— 大小、SHA-256、上传时间。
- **Encrypted configuration blob** — the sealed, client-side-encrypted
  configuration. 加密配置数据块 —— 客户端加密后的封密配置。
- **Diagnostic information** — only when the user explicitly uploads it,
  after reviewing its contents. 诊断信息 —— 仅当用户审核内容后明确上传。

## Purpose / 用途

Cloud storage · Security · Abuse prevention · Device identification ·
Configuration management · Diagnostics. 云端存储、安全、滥用防护、设备识别、
配置管理、诊断。

## What we never do / 我们绝不做

- **No advertising profiling.** 不做广告画像。
- **No selling of user information.** 不出售用户信息。
- **No unrelated tracking.** 不做无关追踪。
- The cloud service **does not store your passphrase** and cannot decrypt
  your configuration. 云服务**不存储你的口令**，无法解密你的配置。

## Your responsibilities / 你的责任

Keep an independent local backup of important data; if you lose your
encryption passphrase, your encrypted configuration may become
unrecoverable. 请为重要数据保留独立的本地备份；若丢失加密口令，加密配置可能
无法恢复。

## Re-viewing this policy / 再次查看

In the app: **Settings → Privacy** (Privacy Policy). 应用内：**设置 → 隐私**
（隐私政策）。
